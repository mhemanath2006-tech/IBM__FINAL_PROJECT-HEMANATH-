# Face Attendance

College attendance by face scan. Teachers open a daily session, students scan their own face
(with a random head-turn check against photos), and reports export to Excel.

Roles: **admin** (adds users, registers faces) · **teacher** (sessions, manual marking, reports) · **student** (scan, own history).

See `DEPLOY.md` for setup and deployment.
